# RecipeNet — Recipe Social Network

A dynamic social network for sharing recipes: users upload recipes with photos, like and comment.

## Tech stack
- PHP · MySQL
- jQuery · Bootstrap

## Features
- Registration/login with client- and server-side validation
- Recipe upload with image
- Likes and comments via AJAX endpoints (`api/`)
- User profiles and guest view

## Getting started
1. Import `database/schema.sql`.
2. Set credentials in `config/db.php`.
3. Serve with Apache (the `uploads/` folder must be writable).
